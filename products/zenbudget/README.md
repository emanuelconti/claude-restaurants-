# ZenBudget — The Finance Planner That Fits On One Screen

A complete personal-finance Excel/Google Sheets planner: budget vs. actual,
transaction log, savings goals, debt payoff tracker, subscription tracker,
and a 12-month overview — with a live dashboard and charts, all driven by
formulas so it updates itself as you fill it in.

## What you get

- `ZenBudget_Planner.xlsx` — the finished product, ready to sell/deliver as-is
- `generate_zenbudget.py` — the generator script (openpyxl), in case you want
  to rebrand, re-theme or extend it before selling your own version

## Sheets included

1. **Dashboard** — income, planned vs. actual expenses, savings rate, and a
   pie chart of where the money goes, all pulled automatically from the
   other tabs
2. **Monthly Budget** — 13 built-in categories, planned vs actual with
   automatic difference and color-coded over/under spending
3. **Transactions** — a 100-row log with dropdowns for type and category
4. **Savings Goals** — target vs. saved with an automatic progress bar
5. **Debt Payoff** — balance, APR, minimum payment, estimated months to
   payoff
6. **Subscriptions** — the tab that pays for the planner: see every
   recurring charge and its true annual cost
7. **Yearly Overview** — a 12-month income/expense/net-savings chart
8. **How to use** — a one-page guide inside the file itself

## Compatible with

Excel (desktop or Microsoft 365) and Google Sheets (upload/import the
.xlsx — all formulas, formatting, data validation and charts carry over).

## Selling this yourself

This is deliberately built so you (or a buyer of this toolkit) can:
- Re-run `generate_zenbudget.py` after tweaking the color palette or category
  list to produce your own branded version in seconds
- Sell the finished `.xlsx` as an instant digital download on Gumroad, Etsy
  or your own site — no code needed by the end customer, they just open it
