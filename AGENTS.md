If you work on the social accounts (@socialperks.es, Good Message Studio on Instagram and Facebook, @sincronia.live) or their routines, read `SOCIAL_HANDOFF.md` at the root of this repository first, and update it when you change something. Every task, first thing: read the section "Outreach heartbeat" in `SOCIAL_HANDOFF.md`. If it says ALERT, or its date is more than 3 working days old, tell the owner before anything else: "outreach fermo: controlla le routine Claude (limite di utilizzo o connettori)". Codex never sends emails and never changes routines; see "Who does what" in the same file.
